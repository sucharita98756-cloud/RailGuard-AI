# 🚆 RailGuard AI — Railway Traffic & Level Crossing Safety System

**Smarter Monitoring, Safer Railways.**

RailGuard AI is a web-based railway safety simulation project designed to demonstrate how intelligent monitoring, automatic level crossing gate control, obstacle alerts, and risk analysis can help improve railway crossing safety.

The project simulates train movement between two stations and demonstrates how the system responds to potential hazards such as obstacles and gate failures.

## ✨ Features

- 🚆 **Train Movement Simulation** — Simulates train movement between Station A and Station B.
- 🚧 **Automatic Gate Control** — Demonstrates automatic level crossing gate operation based on train position.
- 📊 **Live Dashboard** — Displays train speed, distance, estimated arrival time, signal status, and gate status.
- 🤖 **Risk Analysis** — Calculates a risk score using simulated conditions such as distance, speed, obstacle status, and gate failure.
- 🚨 **Obstacle Simulation** — Allows users to simulate an obstacle and observe the system's response.
- ⚠️ **Gate Failure Simulation** — Demonstrates how a simulated gate failure affects the safety status.
- 🛑 **Emergency Response Simulation** — Demonstrates emergency handling during simulated hazardous conditions.
- 📋 **Event Log** — Records important simulation events, warnings, and system activities.
- 🔄 **Reset System** — Resets the simulation for another test.
- 📱 **Interactive Interface** — Provides a simple dashboard for monitoring and testing the system.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Train simulation, event handling, gate logic, and risk calculations
- **DOM Manipulation** — Dynamic dashboard updates
- **Rule-Based Logic** — Simulated risk assessment and safety responses

## ⚙️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html` and `script.js` are in the correct locations.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
5. Click **START TRAIN** to begin the simulation.
6. Use the obstacle and gate failure buttons to test different scenarios.
7. Check the dashboard, risk score, alerts, and event log.
8. Click **RESET SYSTEM** to restart the simulation.

## 🧠 How It Works

1. The system simulates train movement along a railway track.
2. JavaScript updates the train's position and related dashboard information.
3. The gate logic checks the simulated train position and changes the crossing gate status.
4. The risk analysis logic evaluates configured safety conditions.
5. Hazard simulations trigger alerts and demonstrate emergency responses.
6. The event log records important system activities for monitoring.

## 🎯 Project Objective

The objective of RailGuard AI is to demonstrate a software-based approach to railway crossing safety through train movement simulation, automatic gate logic, hazard simulation, and risk monitoring.

The project provides a foundation for exploring how web technologies and future computer vision systems could support railway safety applications.

## ⚠️ Disclaimer

**RailGuard AI is an educational simulation and proof of concept.** Its obstacle detection and risk analysis are simulated or rule-based and do not represent a validated, real-world railway safety system.

This project is not connected to real railway signalling equipment and must not be used to control actual trains or railway gates. Any real-world implementation would require extensive testing, certified fail-safe hardware, railway authority approval, and compliance with applicable safety standards.
